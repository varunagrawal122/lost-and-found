# Lost & Found Portal

A simple PHP + MySQL web app for managing lost and found items, built as a semester project.

## Features
- Report lost or found items with images
- Admin dashboard for approvals, deletions, exports
- User messaging system with replies
- Clean, minimal responsive UI

## Setup Instructions
1. Install [XAMPP](https://www.apachefriends.org/index.html)
2. Copy this folder to `C:\xampp\htdocs\LostFound`
3. Start Apache and MySQL in XAMPP Control Panel
4. Import `schema.sql` into [phpMyAdmin](http://localhost/phpMyAdmin/) under database name `lostfound`
5. Visit [http://localhost/LostFound/](http://localhost/LostFound/) in your browser
